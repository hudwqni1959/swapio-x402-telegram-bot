# Swap.io x402: a Telegram bot that pays for swap quotes

An original 90-second explainer prepared for the [Superteam Earn video bounty](https://superteam.fun/earn/listing/make-a-video-about-our-x402-feature). The example shows a Telegram bot requesting a SOL-to-USDC route quote from the Swap.io Agent API, receiving an HTTP 402 payment requirement, paying per request in USDC through x402, and returning a quote to the user.

## Watch

Download or play [`swapio-x402-telegram-bot.mp4`](swapio-x402-telegram-bot.mp4). Format: 1920×1080 H.264 video, AAC English narration, 90 seconds. The storyboard is in [`storyboard.json`](storyboard.json).

## Disclosure

This is an illustrated concept, **not a working bot or a live paid API demo**. No paid call, Solscan transaction, or completed swap is represented. The narration is synthetic. The visuals were created for this entry. A quote is information; the user decides whether to execute any trade.
