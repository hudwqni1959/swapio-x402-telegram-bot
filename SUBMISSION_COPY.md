## Medium draft

Title: A pay-per-quote Telegram bot with Swap.io and x402

A Telegram bot can be useful even when its users ask for a swap route only occasionally. Rather than keeping an API subscription for sporadic requests, it could ask the [Swap.io](https://swap.io) Agent API for a fresh SOL-to-USDC quote when a user needs one. The API can respond with HTTP 402 and payment terms; an x402-enabled client then pays the charge in USDC and retries the request. The bot presents the returned quote and leaves the trade decision with the user.

The attached 90-second video explains the idea. It is a conceptual mockup with synthetic narration. It does not demonstrate a live paid call, a Solscan transaction, or a swap.
